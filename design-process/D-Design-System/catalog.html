Mojud Design System

Stock-control PWA for Bangladeshi FMCG distributors · theme Jamdani Teal

Mojud is a stock-control PWA for Bangladeshi FMCG distributors. This catalog shows every token and all 42 components (33 seeded from DESIGN.md plus 9 new in Phase 7) with live previews in English and Bangla, light and dark. Token values come from the DESIGN.md frontmatter; behaviour from EXPERIENCE.md; cross-cutting decisions DD-1 to DD-10 win where they disagree. Open questions and token gaps are listed in 00-design-system.md.

Version 2026-10-24 (initial)42 ComponentsMode: Custom (Mode B, without Figma)

Method: Whiteport Design Studio (WDS) · Created: 2026-10-24

Getting Started

Installation

/* Mojud is a custom design system (WDS Mode B, no Figma, no component library).
   There is nothing to install. Map the DESIGN.md tokens 1:1 to CSS custom properties: */
:root {
  --colors-primary: #0B5A54;
  --colors-on-primary: #FFFFFF;
  --spacing-target-min: 3rem;
  --rounded-md: 12px;
}
:root[data-theme="dark"] {
  --colors-primary: #63D5C6;   /* {colors.primary-dark} */
  --colors-on-primary: #00211E;
}

Usage

Components are plain HTML and CSS built from the tokens; mark bilingual parts with lang:

<!-- Scan bar [bar-002]: bilingual, accessible name from visible text, no aria-label -->
<button type="button" class="scan-bar">
  <svg aria-hidden="true"><!-- scan icon --></svg>
  <span lang="bn">স্ক্যান করুন</span> <span lang="en">Scan</span>
</button>

Design Tokens

Design tokens provide one visual language across Mojud. All components use these tokens, never raw values.

Source of truth

92 tokens: 58 colours (29 light/dark pairs), 12 typography, 18 spacing and 4 radius, plus elevation and focus-ring definitions. Values mirror the DESIGN.md frontmatter exactly; this catalog adds no values. In this file every colour is a CSS custom property (--colors-primary), redefined for dark mode.

Reference syntax in component files: {colors.primary}, {typography.body}, {spacing.target-min}, {rounded.md}, {components.focus-ring}. Full tables: design-tokens.md · index: 00-design-system.md.

Bangla rules

  • Every token that may carry Bangla has line-height of at least 1.4 (body 1.5).
  • Bangla is never below 16px: meta (14px) never carries Bangla words; use meta-bn.
  • Only the Scan bar and floor primary buttons show both languages, Bangla first.
  • Labels wrap, never clip. Western digits 0-9 in both languages, tabular numerals for quantities and money.
  • Weight 800 on floor numbers and the Scan bar. No all-caps. Money: taka sign with lakh grouping (৳12,45,000).

Radius, elevation and focus

Border radius

rounded.sm

6px · Inputs, choice chips, status tags, sync chips, hidden-during-count

rounded.md

12px · Cards, buttons, toasts, quantity fields, viewfinder corners

rounded.lg

16px · Scan bar, sheet top corners, dialogs

rounded.full

9999px · Stock-state pills and the count badge only

Soft corners everywhere; no sharp-cornered surfaces, no pill-shaped buttons.

Elevation

card

1px border + at most 0 1px 2px at ~6% (light). Dark: no shadow.

floating

0 6px 16px at ~25% (light): toast, sheets, dialogs. Dark: no shadow; raised items use surface-alt.

fixed bottom zone

1px border top edge, no shadow.

Elevation is prose in DESIGN.md (approximate opacities), not tokens.

Focus ring

2px inner line in surface plus 3px outer line in text on :focus-visible. One of the two lines is always at least 3:1 against what it touches; it never uses primary.

Press Tab to see the live ring on any control on this page. Component: components/focus-ring.md.
