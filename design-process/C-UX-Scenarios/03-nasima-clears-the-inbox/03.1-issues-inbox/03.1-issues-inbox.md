## Overview

**Page Purpose:** Show the one ranked list of open Issues this User may decide, worst first, and let the User decide the simple ones in one tap straight from the card (FR-31, FR-30, FR-33a).

**User Situation:** Nasima, Supervisor at Narayanganj, 17:40 at the small desk by the bay, twenty minutes before the shift ends, on her own Android phone. Today brought two Damage flags, a receipt Shortfall and a Transfer shortage. She hopes to close everything before she goes home; she worries about approving something wrong and carrying the blame. Mojud opens straight on this page (Supervisor home, EXPERIENCE.md → Home and navigation per Role).

**Success Criteria:**
- Every open Issue she may decide is on one list, in the FR-31 order: assigned to her, then affecting Reserved stock, then value at risk (quantity × Unit cost), then oldest.
- Each card shows type, Product, quantity, Warehouse, who raised it and when, so she can decide simple cases without opening the detail (FR-31). Value at risk in ৳ is shown only to Stock-value Roles (Owner, Manager, Accountant, FR-4); Supervisors and Sales reps see quantity and unit instead, never ৳, while the ranking still uses value (DD-2).
- Damage flag, Shortfall, Over-delivery, Transfer overage, Transfer overdue, Dispatch short, Sync conflict and Late count line cards decide in **one tap**, no dialog (FR-30, Interaction Primitives → Confirm vs undo).
- Cases that need a choice or need the evidence read first show only "Open to decide" (Transfer shortage, Discrepancy case, Reversal request), so a write-off is never the only one-tap option.
- The session ends on "No open issues." with every decision recorded under her name (SM-5: Damage flags decided within 24 h).

**Entry Points:**
- App start / sign-in: home for Supervisor and Manager (S12).
- **Issues** tab in the bottom tab bar (phone) or side nav (desktop), with the Count badge.
- Back from 03.2 Issue detail (scroll position kept, EXPERIENCE.md → IA).

**Exit Points:**
- Title link on a card → [03.2 Issue detail](../03.2-issue-detail/03.2-issue-detail.md) (phone: full page; desktop: right-hand detail pane).
- "Open to decide" button → 03.2 Issue detail for that Issue.
- Other tabs: Tasks (S3), Scan (S4), More (S16, S19–S21, S22–S27).
- Empty state reached: she leaves the app (scenario success).

## Technical Notes

- **Ranking** is computed on the server per User (FR-31 [ASSUMPTION]); the client never re-sorts. "Affects Reserved stock" = the Issue's quantity sits in, or was taken from, Reserved (e.g. Damage flag raised from a pick, FR-29; Dispatch short).
- **Visibility:** FR-4 table wins: Supervisor sees only Issues in Assigned Warehouses and only types a Supervisor may decide (never Reversal request; Dispatch short only for orders they created, which Supervisors cannot create, so never). Sales rep sees only Dispatch short for own orders. Server enforces; hidden buttons are not the control.
- **Value display (DD-2):** the server ranks by value at risk for every Role but sends the ৳ amount only to Roles with View Stock value (FR-4); Supervisor and Sales rep payloads carry quantity and unit only.
- **FR-5 check** runs on the server for every decision, including the first render (self-raised flag per Issue from the API).
- **Duplicate safety:** each decision carries a device-generated action ID (FR-14). Double tap → one decision.
- **Concurrency (NFR-4):** a decision on an already-decided Issue returns the existing decision; the client shows "Already decided by …".
- **Offline:** decisions are not queued (State Patterns → Offline, Decided). The cached list is read-only.
- **Live regions:** one polite (`role="status"`) and one assertive region exist from page load; text is replaced, not re-created.
- **Accessibility:** card is an `<article>` labelled by its title link; value at risk and meta are in the article, buttons are siblings of the link; Bangla `lang="bn"` on the page when Bangla is chosen, Product / User names unmarked. Works at 320 CSS px, 400% zoom, 200% text, text-spacing overrides.
- **Dark mode:** same layout, `-dark` tokens.
- **Banned here:** infinite scroll, swipe-to-decide, pop-up notifications, confirmation dialogs on decisions, animations > 200ms.
- **Decided Issues** leave the list; FR-32 says they stay findable by search; the search entry point is not designed yet (Open Questions #7).
