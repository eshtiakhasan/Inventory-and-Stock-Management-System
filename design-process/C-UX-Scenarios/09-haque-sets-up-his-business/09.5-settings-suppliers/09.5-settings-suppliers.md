## Overview

**Page Purpose:** Let the Owner or Manager check, create, edit and archive the companies the Business buys from, each with a name, contact person, phone number and address (FR-19), so they can be chosen on Purchase orders (FR-20).

**User Situation:** Mr. Haque has imported his supplier list (09.3, card 2) or follows the setup strip "Next: Add suppliers" from Products. He scans the list for the suppliers he orders from every week, fixes a phone number, adds one that was missing, then moves on to users.

**Success Criteria:**
- The imported Suppliers are visible at once with their contact person and phone, so a missing phone stands out.
- Adding a Supplier needs only a name; the other fields are optional and say so.
- Archiving a Supplier with open Purchase orders is refused with the order numbers.

**Entry Points:**
- [04.1 Owner view](../../04-haque-traces-an-unexplained-loss/04.1-owner-view/04.1-owner-view.md) first-use step 3 "Add suppliers".
- Setup strip on 09.3 / 09.4 "Next: Add suppliers" (scenario path from 09.4).
- [09.3 Excel import](../09.3-settings-excel-import/09.3-settings-excel-import.md) result → "Check suppliers".
- Settings section link "Suppliers"; phone: More → Settings → Suppliers.
- [09.7 Purchase orders](../09.7-purchase-orders/09.7-purchase-orders.md) Supplier field → "Add a new supplier" (opens this form, returns to the PO) [ASSUMPTION].

**Exit Points:**
- Setup strip "Next: Add users" → [09.6 Settings: Users](../09.6-settings-users/09.6-settings-users.md) (scenario exit: "Moves on to users").
- "Import from Excel" → [09.3](../09.3-settings-excel-import/09.3-settings-excel-import.md).
- An open PO number in the archive refusal → [09.7](../09.7-purchase-orders/09.7-purchase-orders.md) PO detail.

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Empty | No Suppliers | Empty sentence; Import (primary) + Add | Import; add |
| After import (scenario) | Suppliers imported | List; missing values read "No phone" / "No contact person"; setup strip step 3 | Open, fix, add; go on to Users |
| No search result | Search finds nothing | "No supplier found for '{q}'" + Add supplier | Add; clear |
| Form open | Add / row | Panel or full-screen form | Save, Cancel |
| Field error | Empty or duplicate name, bad phone | Inline error; summary for 2+ | Fix |
| Saving / Saved | Save | Spinner then toast; row updated | — |
| Archive refused | Open POs | Disabled Archive + refusal with PO links | Open PO |
| Archive confirm / archived | No open POs | Dialog; row moves to Archived | Restore |
| Loading | First load | Skeleton rows | — |
| Offline | No connection | Banner; "as of (offline)"; Add / Save / Archive disabled "Needs internet" | Read |
| Error | Load / save fails | "Couldn't load suppliers. Try again." / "Couldn't save. Try again." | Retry |
| Role-based visibility | Not Owner / Manager | Hidden; deep link "You don't have access to this." | Own home |
| Dark mode | Setting | `-dark` tokens | Same |

## Form Validation

Same rules as Suppliers import rows in [09.3](../09.3-settings-excel-import/09.3-settings-excel-import.md#form-validation).

### Validation Rules

| Field | Rule | Error Code | Error Message (EN) |
|-------|------|------------|--------------------|
| Name | Required; 2–80 characters [ASSUMPTION] | `ERR_SUPPLIER_NAME_REQUIRED` / `ERR_SUPPLIER_NAME_LENGTH` | "Enter the supplier's name." / "Use 2 to 80 characters." |
| Name | Unique, ignoring case and extra spaces | `ERR_SUPPLIER_NAME_TAKEN` | "You already have a supplier called {name}." |
| Contact person | Optional; ≤ 60 characters | `ERR_SUPPLIER_CONTACT_LENGTH` | "Use up to 60 characters." |
