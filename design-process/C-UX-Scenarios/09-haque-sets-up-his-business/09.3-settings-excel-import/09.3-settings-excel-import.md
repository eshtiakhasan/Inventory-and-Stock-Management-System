## Overview

**Page Purpose:** Move the Business's existing lists into Mojud without typing: download a template for **Products**, **Suppliers** or **opening stock** (FR-46), fill it in Excel, upload it, check a preview that lists every valid row and every error with its row number and reason (FR-47), and confirm. Nothing is saved until he confirms; error rows are skipped; opening stock rows become "opening balance" Stock movements (FR-16, FR-47).

**User Situation:** Mr. Haque, Friday evening on his laptop, with his product and supplier lists already open in Excel. He has just added Narayanganj and Gazipur. He wants this to be the step where Mojud saves him an evening, not costs him one. His worry: entering everything twice.

**Success Criteria:**
- He sees the three steps in the order that works (Products → Suppliers → opening stock) and why opening stock comes last.
- The preview tells him in plain words, by **Excel row number**, what is wrong ("Row 14: Conversion factor missing") so he can fix it in the sheet he already has open.
- Valid rows import even when some rows have errors; he can fix and re-upload only the error rows later.
- An all-errors file shows only the error list and no Confirm import button; nothing is saved (UJ-8 failure path).
- After confirming, he sees exactly what was imported and goes straight to check it in Settings: Products (scenario exit).
- Business success: setup completes in one evening without a consultant (SM-7).

**Entry Points:**
- [04.1 Owner view](../../04-haque-traces-an-unexplained-loss/04.1-owner-view/04.1-owner-view.md) first-use checklist: "Import products from Excel" (step 2) and "Add opening stock" (step 4).
- Setup strip on [09.2 Warehouses](../09.2-settings-warehouses/09.2-settings-warehouses.md) "Next: Import products from Excel" (scenario path).
- Settings section link "Excel import"; phone: More → Settings → Excel import.
- "Import from Excel" links on the empty states of [09.4 Products](../09.4-settings-products/09.4-settings-products.md) and [09.5 Suppliers](../09.5-settings-suppliers/09.5-settings-suppliers.md).

**Exit Points:**
- Result view → "Check products" → [09.4 Settings: Products](../09.4-settings-products/09.4-settings-products.md) (scenario exit: "Confirms import; error rows skipped").
- Result view → "Check suppliers" → [09.5 Settings: Suppliers](../09.5-settings-suppliers/09.5-settings-suppliers.md).
- Result view (opening stock) → [04.1 Owner view](../../04-haque-traces-an-unexplained-loss/04.1-owner-view/04.1-owner-view.md), which now shows Stock value (first use ends when opening stock exists).

## Form Validation

Two levels: **file checks** (whole file refused before preview) and **row checks** (each row valid or listed as an error in the preview). Row reasons are short, specific and calm, in the Voice and Tone style "Row 14: Conversion factor missing". The same rules apply when the record is typed by hand in 09.4 / 09.5, so a row that imports is a record the form would accept.

### Validation Rules: file

| Check | Rule | Error Code | Error Message (EN) |
|-------|------|------------|--------------------|
| Type | `.xlsx` only [ASSUMPTION] | `ERR_IMPORT_FILE_TYPE` | "Choose an Excel file (.xlsx)." |
| Size | ≤ 5 MB and ≤ 5,000 data rows (NFR-10) [ASSUMPTION] | `ERR_IMPORT_FILE_SIZE` | "This file is too big. Use up to 5,000 rows, or split it into two files." |
| Template | Header row matches this step's template (column names in either language) | `ERR_IMPORT_WRONG_TEMPLATE` | "This is not the {type} template. Download the {type} template and copy your rows into it." |
| Warehouse columns (Products) | Every "Low-stock threshold: {Warehouse}" column names an active Warehouse | `ERR_IMPORT_UNKNOWN_WAREHOUSE_COL` | "Column '{column}' does not match a warehouse. Download a new template." |
| Rows | At least one data row | `ERR_IMPORT_EMPTY` | "The file has no rows under the header." |
| Readable | File opens | `ERR_IMPORT_UNREADABLE` | "This file can't be opened. Save it again in Excel as .xlsx and try again." |

## Technical Notes

- **Permissions (FR-4):** Owner and Manager; enforced on the server for download, check and import.
- **Templates (FR-46):** one header row; each column name in English then Bangla, e.g. "Name / নাম" (EXPERIENCE.md UJ-8 [ASSUMPTION]); a second sheet "How to fill / কীভাবে পূরণ করবেন" with one example row and rules in both languages [ASSUMPTION]. Western digits. Columns:
  - **Products:** SKU · Name · Alternate names (optional, DD-10; header "Alternate names / অন্য নাম" [BN: verify]; several names separated by `;`, e.g. "চাল 25 কেজি; Chal 25"; either language, saved exactly as typed; an old template without this column is still accepted) · Category · Base unit · Pack unit · Conversion factor · Base barcode · Pack barcode · Low-stock threshold: {Warehouse} (one per active Warehouse).
  - **Suppliers:** Name · Contact person · Phone · Address.
  - **Opening stock:** SKU · Product name (for reference, not checked) · Warehouse · Quantity (pack) · Quantity (base) · Cost per pack · Cost per base unit. Pre-filled with active Products × active Warehouses [ASSUMPTION].
- **Row numbers** are Excel row numbers (header = 1). Header detection accepts either language and ignores case and extra spaces.
- **Check then save (FR-47; PRD addendum):** the server validates every row against the file and the database and keeps the result for the preview; Confirm saves the valid rows in **one transaction** with one import ID (FR-14). If the data changed between preview and confirm (e.g. someone added the same SKU), the import re-checks and refuses only the newly invalid rows, then shows a fresh preview instead of saving [ASSUMPTION].
- **Opening stock (FR-16, FR-18, FR-11):** each valid row creates one Move with Reason "opening balance" into Available at that Warehouse, quantity in Base units, and sets the Product's Unit cost (per Base unit). Cost entered per pack is divided by the Conversion factor; display shows both ("৳1,200 per carton · ৳50 per piece"). Movements are permanent; mistakes are corrected by a Reversal (FR-15) from movement history (07.2).
- **Quantities** shown as Pack + Base ("120 ctn + 6 pcs", FR-9); taka with ৳ and lakh grouping.
- **No Scan bar** (DD-4). Nothing about import is available offline (settings need a connection).
- **Focus:** file chosen → preview H1 when checking ends; Cancel → the step's Choose file; dialog → Go back; result → result H1. Preview error list items are not focusable (plain text) but the list is reachable by headings.
- **Large files:** no infinite scroll; "Show more" in steps of 50.
- **Reflow:** at 320 CSS px the preview table becomes stacked rows; long Bangla reasons wrap; file names break anywhere (`overflow-wrap: anywhere`).
