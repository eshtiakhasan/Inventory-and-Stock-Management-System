## Overview

**Page Purpose:** One place for everything about "me" on this device: who is signed in, the interface language, light or dark screen, installing Mojud to the home screen, the Owner's recovery code, and signing out, so a shared phone can be handed over cleanly.

**User Situation:** Karim has just set his own password (10.2) and lands here in the **first-sign-in form**. He wants Bangla, wants Mojud on the phone's home screen like the other apps, and wants to see his tasks. Later visits come from More → Settings → Me, typically to sign out at the end of a shift so the next worker can sign in.

**Success Criteria:**
- Karim sees his name, Role and Warehouse, so he knows the phone is his for now.
- One tap on "বাংলা" switches every word on the screen to Bangla at once, and it stays Bangla for him on any phone (FR-45).
- One tap on Install app opens the browser's install prompt (FR-40); afterwards the page says Mojud is installed.
- "Go to My tasks" takes him to [01.1 My tasks](../../01-karim-receives-a-delivery-blind/01.1-my-tasks/01.1-my-tasks.md) with his name in the app bar.
- Sign out is one tap (with one confirmation only when actions are still waiting to sync).
- Mr. Haque (Owner) can make a new recovery code, which is shown once with Copy and "I have saved it".

**Entry Points:**
- From [10.2 Change temporary password](../10.2-change-temporary-password/10.2-change-temporary-password.md) after saving (first-sign-in form, `?first=1`).
- Phone: More tab → Settings → Me. Desktop: side nav Settings → Me.
- The app bar's signed-in name is not a link (Open Question 8).

**Exit Points:**
- "Go to My tasks" (first-sign-in form only) → Role home: [01.1 My tasks](../../01-karim-receives-a-delivery-blind/01.1-my-tasks/01.1-my-tasks.md) for Warehouse worker (label follows the Role home, see object `settingsme-first-continue`).
- Back (phone) → More. Tabs and side nav as usual.
- Sign out → [10.1 Sign in](../10.1-sign-in/10.1-sign-in.md).

## Layout Structure

Settings list page: sticky app bar, then sections stacked as cards (Account, Language, Screen colour, Shared phone (DD-8), Install app, Recovery code for Owner, Sign out). Phone: bottom tab bar for the Role, **no Scan bar** (DD-4: Settings is not a floor screen; the Scan tab stays in the tab bar for floor Roles). Sign out sits last, in the bottom third, away from other buttons.

Desktop sections use a two-column row (label left 12rem, control right) from 1024px; below that they stack as on the phone. The Settings sub-navigation (Users, Warehouses, Products, Suppliers, Excel import, Me) is owned by the 09.x Settings pages; Me is its last item. **Short screen / landscape / text ≥ 150%:** app bar compacts (name + status); the tab bar moves to the end of the content (DESIGN.md → Layout); chips wrap.

## Technical Notes

- **Language (FR-45):** saved on the User record; applied on every device after sign-in. Changing it here also updates this phone's pre-sign-in language (10.1 decision L1).
- **Theme:** stored on the device; default "Device setting" (`prefers-color-scheme`) [ASSUMPTION].
- **Install (FR-40):** capture Chrome's `beforeinstallprompt` once per page load and keep it for the button; detect installed mode with `display-mode: standalone`. No custom install banners elsewhere; this page is the install entry (Responsive & Platform), and the first-sign-in form is the one-time prompt.
- **Recovery code (FR-54):** generating a new one cancels the old one immediately in the same server transaction; the new code is returned once and never stored in plain text (hash only, NFR-6); the client never caches it, never writes it to storage or logs, and clears it from memory after "I have saved it" or leaving. Owner Role checked on the server (FR-4).
- **Sign out (DD-8):** ends the session on this device; clears the User's private data from the phone except queued actions, which carry their author and a signed per-session action token and sync in order (FR-43) after sign-out [ASSUMPTION: signed action tokens to be confirmed in architecture]. Another User signed in later cannot edit, discard or re-send them.
- **Shared phone setting (DD-8):** stored per device; read by 10.1 / 10.2 to set `autocomplete="off"` and the "don't save" hint. The shared catalogue and stock cache may stay for the next User of the same Business.
- **Shared phones (PRD §9 Q2 open):** name in the app bar and the Account card; one-tap Sign out in More and here (Decided).
- **Live regions:** polite (language, install result, copy result) and assertive (errors) regions exist from page load.
