> R-01 Reviewer note: The clean-up is one Kysely transaction with `pg_try_advisory_xact_lock`, so the lock and the DELETE share a connection and the lock is released at commit or rollback. The concurrent-run test I asked for is not stated, but the design is sound.

> R-02 Reviewer note: The health check uses `-h 127.0.0.1`, `$$` escaping and `start_period`. The Compose v2.17 minimum is recorded and `verify` checks it.

> R-03 Reviewer note: The cookie is `mojud_session`, matching C1.

> R-04 Reviewer note: `authenticate` is now one joined SELECT that returns `csrf_token` and `active`. Expiry and inactive users delete the session and return SESSION_ENDED. `csrfCheck` runs before `extendSession`. Performance-design states 2 round trips, consistent with security-design.

> R-05 Reviewer note: Every body-parser error is now mapped to 401 on sign-in, and `originCheck` runs before parsing. The stated mechanism does not work as written: `errorHandler` "checks `req.route`", but `express.json` is app-level middleware that runs before routing, so `req.route` is undefined when a parser error is raised. The sign-in mapping would never fire. The specified malformed-JSON test would catch this, so I grade it Minor.

> R-06 Reviewer note: The include file is applied in every location, with `always`. nginx adds nothing on `/api/`. `theme-init.js` and `index.html` are no-cache. The CSP is extended. The smoke test checks `/`, an asset and `theme-init.js`.

> R-07 Reviewer note: Global lookups are listed with a naming rule and a test. The `as BusinessId` cast is banned by ESLint. See the new Minor below for a gap in the list.

> R-08 Reviewer note: Referer origin parsing, `null` handling and the CSRF length check are specified.

> R-09 Reviewer note: `normalizePhone` returns null and the sign-in path uses a single verify.

> R-10 Reviewer note: A custom SQL migration provider and a Dockerfile copy are designed, and `migrate` has `restart: "no"`. Shutdown now stops the clean-up before `pool.end()`.

> R-11 Reviewer note: The `X-Response-Time` refinement is stated as deliberate. It is still absent from the pipeline table, which is cosmetic.
