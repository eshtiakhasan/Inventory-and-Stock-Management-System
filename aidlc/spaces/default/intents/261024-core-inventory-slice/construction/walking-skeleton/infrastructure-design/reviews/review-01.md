### Summary

The pipeline order and the Q1 to Q3 choices are sound. The `APP_ORIGIN` comma-separated list contradicts the exact-match Origin check and would make every sign-up and sign-in return 403, so the smoke test cannot pass. The test-database creation depends on an init script that only runs on a fresh volume, the smoke test is not repeatable against a kept volume, and the health-check timings do not fit the 60 s start-up budget.
